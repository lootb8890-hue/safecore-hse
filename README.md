# SafeCore HSE Platform (Enterprise SaaS) 🛡️

**SafeCore HSE Platform** هو الحل المرجعي الشامل ذو المنصات الهجينة والـ **Multi-Tenant White-Label SaaS** لإدارة السلامة والبيئة والصحة المهنية في المصانع، الشركات النفطية، المستشفيات، والقطاعات الإنشائية الكبرى حول العالم، مُنفَذ وفق أعلى المقاييس الهندسية العالمية والمعايير الدولية (**OSHA 29 CFR**، **ISO 45001**، **NFPA**).

---

## 🏗️ هيكلية ومعمارية النظام (Clean Enterprise Modular Ecosystem)

يتوزع المشروع على وحدتين رئيسيتين تشكلان منظومة سحابية متقدمة تدعم العمل بدون اتصال (**Offline-First**) والتخصيص التلقائي لكل عميل (**Runtime White-Label Branding**) دون تعديل في الكود:

```
SafeCore-HSE/
 ├── docs/                         # التوثيق الشامل (SRS, API Specs, DB Schema, UI/UX Design System)
 ├── backend/                      # خادم الأسطورة السلس Enterprise NestJS + Prisma ORM + Socket.io
 │    ├── prisma/                  # تعريف الجداول بالـ Schema وبرنامِج حقن بيانات الأسطول (seed.ts)
 │    └── src/modules/             # الوحدات العشرة المتطورة (Tenants, Auth, Assets, Layouts, etc.)
 ├── flutter_app/                  # تطبيق واجهة المستخدمين الشامل الهجين (Android, iOS, Web, Desktop)
 │    ├── lib/core/                # محركات التصميم الأبيض، المزامنة، قواعد بيانات Offline Hive
 │    └── lib/features/            # شاشات لوحة الإدارة، المخططات التفاعلية، مسح QR، وزر الطوارئ الفوري
 ├── k8s/                          # إعدادات الحاويات وقفل Wildcard Subdomains على Kubernetes
 └── docker-compose.yml            # إعداد البيئة السحابية محلياً في أمر واحد
```

## 🚀 كيفية التوليف والتجربة (One-Click Setup)

### 1. إدارة قاعدة البيانات وتشغيل الخادم (NestJS API & Sockets):
```bash
# 1. الدخول لمجلد الخادم وتثبيت الحزم المجمعة
cd backend && npm install

# 2. توليد عميل Prisma ORM
npx prisma generate

# 3. تشغيل برنامج حقن البيانات التوضيحية (Refinery Tenant & Hospital Tenant)
npx ts-node prisma/seed.ts

# 4. تشغيل خادم المنصة على الـ Port 4000
npm run start:dev
```
> 💡 **مسار الـ API:** `http://localhost:4000/api/v1`  
> 💡 **مسار الـ Real-time Sockets:** `ws://localhost:4000/hse`

### 2. تشغيل وتجربة المنظومة التفاعلية في تطبيق Flutter:
```bash
# 1. الانتقال إلى بيئة Flutter التطبيقية
cd flutter_app && flutter pub get

# 2. تشغيل التطبيق على متصفح Chrome أو أي محاكي متاح (Windows, Web, Mobile)
flutter run -d chrome
```

## 🔥 الخصائص الحصرية والتقنيات العميقة المنجزة في الإصدار:

1. **المحرك التفاعلي للمخططات الهندسية (Interactive Layout Studio):**
   * دعم استبدال الخرائط العادية برسوم الكتل الهندسية ومخططات المباني (Floor Plans).
   * إمكانية الفرز بالـ **8 Layer Pills** الحصرية:  
     `EXTINGUISHER`, `EMERGENCY_EXIT`, `FIRST_AID`, `ALARM`, `ELECTRICAL`, `HAZARD_ZONE`, `SAFETY_EQUIPMENT`, `CAMERA`.
   * تمرير الأصابع للتكبير والضغط على الإبرة لرفع تقرير أو بدء الفحص بلحظتها.

2. **التخصيص التلقائي لكل عميل (White-Label Dynamic Branding):**
   * عند إدخال الـ Subdomain (مثلاً: `petroapex` لمصفاة نفط، أو `alnoor` لتعاونية مستحضر طبي)، يُبدِّل النظام لونه وشعاره فورياً، مع دعم الاتجاهين **LTR** و **RTL** العربية دون إغلاق التطبيق!

3. **نظام ملصقات الطباعة الصناعية التلقائي (Automated Adhesive Sticker Engine):**
   * عند إنشاء أي أصل جديد (طفاية، صندوق إسعافات)، يولد الخادم أوتوماتيكياً رابط **QR Code cryptographically sound** مع رقم **Barcode خطي 128**.
   * زر مخصص لإظهار وطباعة الملصق التعريفي الجاهز للماكينة الصناعية متضمناً شعار الشركة الأم والرقم المعالج.

4. **مركز الطوارئ وزر الإشعار الحي الصوتي (Zero-Latency Emergency Siren):**
   * عند ضغط المراقب أو العضو على الزر الأحمر الكبير في شاشة الـ SOS، تنطلق موجة إشعار سلكي (WebSockets) تثير صوت صافرات إنذار صوتي حقيقي ورجاج اهتزازي لكافة مشغلي ومفتشي القطاع في اللحظة والثانية!
   * بنية جاهزة لربط الإشعار بالهيئات والبلديات ومراكز المراقبة الخارجية دون إهدار الوقت بالاتصال الهاتفي.

5. **المزامنة والعمل دون اتصال (Offline-First Storage):**
   * تمكين الفنيين من إجراء فحوصاتهم التفتيشية الشاملة حتى في الأماكن المغطاة تحت الأرض والأنفاق السفلية؛ يتم التئام القفل محلياً، وبمجرد عودة الإنترنت، يبرم المحرك **Sync Engine** رفعة جماعية سلسة للخادم.

6. **الذكاء الاصطناعي لتحليل الصور (AI Vision Compliance Diagnostic):**
   * إمكانية مسح أو رفع صور موقع العمل ليكتشف نموذج الرؤية نقص الـ **PPE** (كعناوين خلو العمال من واقيات الرأس) أو انسداد مخارج الطوارئ مع استدلال مباشر بربط الباراجراف القانوني في معايير **OSHA**.
   * تلخيص التقارير التفتيشية أوتوماتيكياً وصناعة مصفوفات التقييم الوقائي بالمخاطر للمديرين التنفيذيين.

7. **السجل التفتيشي الأبدي (Immutable Audit Trail):**
   * تطبيق معيار الصرامة التشريعية: كل حرف أو تعديل يُقيد بالمسجل واللحظة والقيم المغيرة بالتدقيق التام، ولا توفر المنصة **أبداً** أي واجهة برمجية للحذف أو التصفية!
